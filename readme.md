VitEnergo Project – Система управления заявками
Прототип системы для автоматизации подачи, согласования и обработки заявок на мероприятия. Проект реализует полный цикл документооборота с ролевой моделью доступа и уведомлениями в реальном времени.



Функциональность
Ролевая модель: 4 уровня доступа (Сотрудник, Модератор, Согласующий, Администратор).
Workflow: Жизненный цикл заявки (Новая → Модерация → Согласование → Одобрение/Отказ).
Real-time Мгновенное обновление списков, статусов и чатов через WebSocket.
Работа с файлами: Загрузка документов, скачивание по одному или ZIP-архивом, проверка на дубликаты.
Админка: Управление пользователями и просмотр системных логов действий.
Безопасность: JWT Auth, хеширование паролей, защита от Brute-force.



Технический стек
Backend: Node.js, Express.js
Database: Microsoft SQL Server 2022
Frontend: HTML5, CSS3, Vanilla JS (SPA-подход без фреймворков)
Драйвер БД: mssql (native)



Установка и запуск
1. Клонирование репозитория
Скачайте проект в локальную папку:
git clone https://github.com/olegsandoor/vitpr.git

2. Установка зависимостей
Папка node_modules исключена из репозитория для оптимизации. Установите библиотеки командой:
npm install

3. Настройка Базы Данных (MS SQL Server)
В корне проекта находится файл db.bak – это полная резервная копия базы данных с пользователями и структурой.
Откройте SQL Server Management Studio
В обозревателе объектов: Базы данных (ПКМ) -> Восстановить базу данных.
Выберите Устройство -> Нажмите ... -> Добавить -> Выберите файл db.bak
Нажмите ОК.
Важно: Для подключения приложения используется SQL-аутентификация. Вам нужно убедиться, что пользователь существует:
Перейдите в Безопасность -> Имена входа
Создайте (или проверьте) пользователя:
Логин: VitEnergoUser
Пароль: VitEnergo123!
Права: Роль db_owner для базы VitEnergoProject



4. Конфигурация
Файл .env включен в репозиторий для быстрого старта. Убедитесь, что параметры совпадают с вашим SQL-сервером:
DB_SERVER=localhost
DB_DATABASE=VitEnergoProject
DB_USER=VitEnergoUser
DB_PASSWORD=VitEnergo123!

5. Запуск сервера
node server.js
После успешного запуска откройте браузер: http://localhost:3000
